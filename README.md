# Inventory & Supply Chain Management Analytics

## Project Summary

This repository contains a practical inventory and supply chain analytics exploration built from a structured inventory dataset. It includes:

- `Inventory management dataset.csv` — the source data for analysis
- `Inventory_Management_EDA.ipynb` — Python notebook for exploratory data analysis, charts, and summary metrics
- `Inventory and Supply Chain Management Analysis.pbix` — Power BI project file for dashboard reporting
- `Inventory & Supply Management Dashboard.png` — exported dashboard screenshot

The analysis focuses on inventory performance, transportation costs, lead time, and backorder trends to support operational decision-making.

## What is included

- Data profiling and EDA using Python and pandas
- Inventory turnover and warehouse utilization insights
- Cost breakdown by region and product category
- Lead time and fulfillment performance review
- Power BI dashboard prototype for executive-level reporting

| File | Purpose |

## How to use

1. Open `Inventory_Management_EDA.ipynb` in Jupyter Notebook or JupyterLab.
2. Review the data loading, cleaning, and chart sections.
3. Open the Power BI file in Power BI Desktop to inspect the dashboard and measures.

This repository is intended as a personal analytics project showcasing inventory and supply chain analysis using Python, Jupyter, and Power BI.
